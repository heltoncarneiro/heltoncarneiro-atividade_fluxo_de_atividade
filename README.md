# API de Filmes

API REST simples usando **Node.js + Express**.  
Nesta versão temos duas rotas: **GET** e **POST**.

## Como executar
```bash
npm install
node index.js
```

## Endpoints
- **GET** http://localhost:5000/api/filmes → retorna a lista de filmes
- **POST** http://localhost:5000/api/filmes → adiciona um novo filme

## Workflow
Utilizado o **GitHub Flow**: cada feature é criada em uma branch e integrada à `main` via Pull Request.
